# מדריך למערכת המיקס האוטומטית (AI & Developer Guide)

קובץ זה מיועד עבורך, ועבור כל מודל בינה מלאכותית (AI Agent) שיפתח את הפרויקט הזה בעתיד או ממכשיר אחר.
הוא מכיל את כל הידע, ההחלטות הארכיטקטוניות, והלקחים הטכניים שנצברו כדי להבטיח עבודה חלקה ומיידית ללא תקלות.
לאחר כל פעם שמיני פרויקט מסתיים הסוכן חייב לעדכן כאן את הקובץ ולהוסיף את המסקנות ומידע שהוא צבר. ככה הקובץ יהיה מעודכן תמיד.

---

## 📌 מטרת המערכת (Project Mission)
מערכת אוטומטית מלאה לעיבוד, חיתוך, נירמול עוצמות ומיקסוס רצועות אודיו מיוטיוב לכדי קובץ מאסטר אחד רציף ואיכותי:
- **פלט סופי**: קובץ MP3 בקצב 320kbps CBR וקובץ WAV (16-bit PCM, 44.1kHz Stereo).
- **מעברים**: Crossfade שווה-עוצמה (Equal-Power Sine/Cosine) המונע נפילות ווליום בין מעברים.
- **מעברי Direct Drop**: תמיכה בכניסות חדות של אפקטים (כגון יריות או דרופ של טראנס) ללא עמעום של תחילת המקטע.

## ⚠️ לקחים קריטיים ופתרון בעיות (Crucial Lessons Learned - Must Read!)

אם אתה מודל AI שמריץ פקודות בסביבה זו, **הקפד לפעול לפי הכללים הבאים שנלמדו מניסיון מעשי**:

### 1. שגיאות רשת ואימות SSL ב-Windows (Schannel Revocation Offline)
- **הבעיה**: ב-Windows, אימות ה-CRL של Schannel נכשל לעיתים קרובות עם השגיאה:  
  `schannel: CRYPT_E_REVOCATION_OFFLINE (0x80092013)`.
- **הפתרון שנבנה במערכת**:
  - בהורדות דרך `yt-dlp` חובה להשתמש בדגל: `--no-check-certificates`.
  - בקריאות `curl` חובה להוסיף: `--ssl-no-revoke`.
  - התקנות `pip` דורשות `--default-timeout 120`.

### 2. חסימות ומגבלות יוטיוב (YouTube Extractor Issues)
- **הבעיה**: לקוח ה-Web הרגיל של יוטיוב מחזיר שגיאות עקב שינויי נגן ו-JS (שגיאות כמו "Video unavailable" או 403).
- **הפתרון שנבנה במערכת**:
  - `audio_mixer.py` מגדיר מראש: `--extractor-args "youtube:player_client=android"`.
  - דגל זה מאפשר הורדה מהירה, יציבה וללא צורך ב-JS Engine חיצוני.

### 3. פערי ווליום קיצוניים בין שירים (Loudness Balancing)
- **הבעיה**: שירים ישנים או הקלטות מהטלפון מגיעים בווליום נמוך מאוד (למשל מוביט ב-`-25 LUFS`), בעוד טראקים מודרניים מגיעים בווליום מפוצץ (למשל `-6.4 LUFS`).
- **הפתרון שנבנה במערכת**:
  - המערכת מחשבת RMS ומנרמלת באופן דינמי לרמת מאסטר קבועה (`target_rms = 0.18`, שווה ערך ל-`-15 dB RMS`).
  - קיים True Peak Limiter שמגביל את העוצמה ל-`-0.3 dBFS` (0.965) כדי למנוע דיסטורשן (Clipping).
  - ניתן להגדיר לכל שיר פרמטר `"boost": 1.2` או ערך אחר במידת הצורך ב-`tracks.json`.

### 4. כניסות חדות ("אפקט יריות" / Drops)
- **הבעיה**: ב-Crossfade רגיל, השיר הנכנס מתחיל בווליום 0 ועולה לאט במשך 2 שניות. זה "בולע" אפקטים שמתחילים מיד, כמו יריות אקדח או כניסת תופים.
- **הפתרון שנבנה במערכת**:
  - הוגדר מאפיין `"direct_drop": true`.
  - במצב זה, השיר היוצא דועך בצורה מוזיקלית (Fade-out של 1.6s), והשיר הנכנס נוחת **בעוצמה מלאה (Full Punch)** עם מיקרו-פייד של 40ms בלבד למניעת קליקים דיגיטליים.

## 🤖 הנחיות לבינה המלאכותית: כיצד לטפל בבקשת משתמש חדשה

כאשר המשתמש שולח קישורי יוטיוב חדשים וזמנים:

1. **קריאת הקובץ הקיים**: קרא את [`tracks.json`](tracks.json).
2. **הבנת זמני החיתוך**:
   - הפורמט תומך ב-`MM:SS` (למשל `"01:29"`), שניות עשרוניות (למשל `"01:22.7"`), או שניות ישירות (`82.7`).
3. **עדכון `tracks.json`**:
   - הוסף / שנה את רשימת השירים תחת `"tracks"`.
   - מבנה פריט בסיסי:
     ```json
     {
       "url": "https://youtu.be/VIDEO_ID",
       "title": "שם השיר בעברית",
       "start": "01:15",
       "end": "01:54",
       "repeat": 1,
       "crossfade": 2.0,
       "boost": 1.0,
       "direct_drop": false
     }
     ```
4. **הרצת המיקסוס**:
   הפעל את הפקודה בטרמינל:
   ```powershell
   python audio_mixer.py --config tracks.json
   ```
5. **בדיקת התוצאה**:
   - ודא שהסקריפט הדפיס `[v] Master created successfully!`.
   - הצג למשתמש את ציר הזמן (Timeline) המדויק ואת הקישורים לקבצי הפלט `master_audio.mp3` ו-`master_audio.wav`.
